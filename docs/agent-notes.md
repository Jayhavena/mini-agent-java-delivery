# MiniAgent 设计与运行笔记

## 一次问答的五个阶段

1. 接收用户输入，并把用户消息写入当前 session。
2. 组装上下文：系统提示词、工具 Schema、会话摘要、最近消息、工具结果。
3. 让 LLM 输出严格 JSON 协议：`tool_call` 或 `final`。
4. 如果是 `tool_call`，通过注册表找到工具、执行并把结果写回 session；然后再次进入循环。
5. 如果是 `final`，保存回答并返回用户；超过最大轮次则给出降级回答。

## 上下文里放什么

- 必须放：当前用户输入、运行摘要、最近若干条原始消息、工具 Schema。
- 工具调用：保留工具名、参数、结果，以及一句简短的决策说明（thought）。
- 不必放：完整 HTTP 响应、重复的系统提示副本、所有历史 thought 原文。
- 工具状态（例如 todo）保存在 session 的 `toolState` 中。模型需要时再调用 `todo` 查看，避免每轮把完整状态塞进 prompt。

## 压缩策略

上下文超过预算时，保留最近 12 条消息，把更早的消息转成摘要。摘要包含用户诉求、助手结论、工具名和结果要点。
原始消息仍保存在 session JSON 中用于审计，只是不再发送给模型。
